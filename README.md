# 급여대장 엑셀 데이터 읽기 수정본

## 변경 핵심
- 고정된 `r[0]`, `r[1]`, `r[2]` 방식 제거
- `사원명 / 부서명 / 기본급`이 실제로 존재하는 행을 자동으로 헤더로 탐색
- 헤더명 기준으로 지급/공제 컬럼을 매핑
- 빈 값에 임의의 `홍길동`, `물류팀`, `3,000,000` 등을 넣지 않음
- 빈 행 및 사원명이 없는 합계/설명 영역을 자동 제외
- 엑셀 원본 행 번호(`sourceRow`) 보존
- 숫자에 쉼표/원/₩/공백/회계식 음수가 포함되어도 숫자로 변환
- 지급합계, 공제합계, 실 지급액 등 엑셀 원본 계산값도 별도 보존
- 기존 UI/급여 계산 구조는 최대한 유지

## 적용
기존 프로젝트에서 아래 두 파일을 교체하세요.
- `app.js`
- `excel-handler.js`

`index.html`의 스크립트 로딩 순서는 기존처럼 `payroll-engine.js -> excel-handler.js -> app.js`를 유지하면 됩니다.
